PROBLEMAS CRÍTICOS ENCONTRADOS (P0 - SEMANA 1)
================================================================================

1. DASHBOARD LONG POLLING - CRÍTICO ⚠️
   ├─ Latência: 5 segundos por requisição
   ├─ Arquivo: apps/backend/src/services/dashboard/index.ts:33
   ├─ Impacto: 100 clientes = 500s CPU desperdido
   ├─ Solução: WebSocket (8h)
   └─ Ganho: -96% latência (5000ms → 200ms)

2. JSON FILE I/O SÍNCRONO - CRÍTICO ⚠️
   ├─ Bloqueio: 50-200ms por escrita
   ├─ Arquivo: apps/backend/src/services/database/index.ts:51
   ├─ Impacto: Event loop completamente bloqueado
   ├─ Solução: fs.promises.writeFile (2h)
   └─ Ganho: -100% event loop blocking

3. MEMORY LEAKS (Dashboard Listeners) - CRÍTICO ⚠️
   ├─ Vazamento: 43MB/dia com 1000 clientes
   ├─ Arquivo: apps/backend/src/services/dashboard/index.ts:43
   ├─ Problema: Sem cleanup em erro
   ├─ Solução: Try-finally block (1h)
   └─ Ganho: -100% memory leak

4. CONTEXT GLOBAL REACT - CRÍTICO ⚠️
   ├─ Re-renders: 200+/segundo em árvore
   ├─ Arquivo: apps/frontend/src/features/dashboard/provider/dashboardProvider.tsx:13
   ├─ Impacto: 40-60ms latência por update
   ├─ Solução: Split em DevicesContext + ControllersContext (4h)
   └─ Ganho: -70% re-renders

5. EVENTBUS PROMISE.ALL - ALTO ⚠️
   ├─ Bloqueio: Aguarda TODAS callbacks
   ├─ Arquivo: apps/backend/src/services/event-bus/index.ts:24
   ├─ Problema: 1 callback lenta = atrasa todas
   ├─ Solução: Fire-and-forget com timeout 1s (3h)
   └─ Ganho: -99% latência em edge cases
