# Endpoint Types

Tipos de endpoints que podem ser criados no sistema.

## Nomenclatura

- **DO** - Digital Output (Saída Digital)
- **DI** - Digital Input (Entrada Digital)
- **AO** - Analog Output (Saída Analógica)
- **AI** - Analog Input (Entrada Analógica)
- **Dimmer** - Controle de intensidade
- **Counter** - Contador de pulsos
- **Register** - Registrador genérico

## Uso

Cada endpoint implementa uma interface específica com comandos padronizados.

Veja [DO-DI-AO-AI.ts](./DO-DI-AO-AI.ts) para as definições completas.
